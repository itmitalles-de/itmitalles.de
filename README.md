# IT mit alles

Statische Website für den Giesinger IT-Service. Die Seite besteht bewusst nur aus HTML, CSS und einem kleinen JavaScript für die mobile Navigation. Dadurch bleibt sie schnell, günstig und leicht zu pflegen.

## Veröffentlichung

Ein Push auf `main` startet `.github/workflows/pages.yml` und veröffentlicht die Website über GitHub Pages.

## Vor dem öffentlichen Start

- Impressum mit echtem Namen, ladungsfähiger Anschrift und Kontaktdaten ausfüllen.
- Datenschutzerklärung auf die tatsächlich verwendete Mail- und Hosting-Infrastruktur abstimmen.
- Prüfen, ob `kontakt@itmitalles.de` als Postfach eingerichtet ist.
- DNS für `itmitalles.de` und optional `www.itmitalles.de` auf GitHub Pages zeigen lassen.

## Inhaltliche Leitlinie

Die Positionierung folgt dem vorhandenen Businessplan: kleine Firmen und Teams bis etwa zehn Mitarbeitende, Freiberufler und Privatpersonen; Netzwerk und WLAN, Geräte und Arbeitsplätze, Server und Cloud sowie E-Commerce und Web. Das Angebot ist Hilfe auf Zuruf nach aktueller Verfügbarkeit, ohne starre SLAs oder unnötige monatliche Pauschalen.
